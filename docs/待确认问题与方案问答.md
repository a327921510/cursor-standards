## Q7 下发规则是否加 `standards-` 命名前缀？

**背景**：规则已隔离在 `.cursor/rules/standards/` 子目录（路径不冲突），但 Cursor 的 `@rule-name` 手动引用是按**规则名**。若项目 local 规则与下发规则重名（如都叫 `git-workflow`），`@` 引用会有歧义。

- 选项 A（当前）：保持原名 `general.mdc` 等。
- 选项 B：下发文件统一加前缀，如 `std-general.mdc`、`std-git-workflow.mdc`，避免 @ 引用歧义。

**推荐**：**B**（更稳妥，几乎无成本）。若你更看重规则名简洁 → A。

**推荐**：**A**。需你确认使用 GitHub Actions（还是 GitLab CI / 其他）。
